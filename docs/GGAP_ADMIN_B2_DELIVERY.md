# 總後台 B2：共用表格與全域樣式（第一批）

日期：2026-09-07。僅本地前端修正，延續既有 9/5 基準與已核准修改；不推送、不部署、不更動業務資料。

## 完成範圍

本批涵蓋 10 個檔案（部分依路由呈現多個頁面），不是全站完成聲明：

- 平台管理：帳號／角色／敏感權限／資料範圍、語言地區與時區、系統紀錄、平台參數、通知規則與紀錄。
- 財務設定：幣別管理、匯率管理與歷史。
- 財務對帳：三類對帳清單、詳細、差異案件。

其中 20 張原生 ElTable 改用既有 ArtTable；加上原已使用共用組件的對帳清單，本批檢查共涵蓋 21 張表格宣告。不新增第二套表格組件。

## 具體行為

1. 移除強制邊框設定，繼承共用表格的邊框、斑馬紋、尺寸與表頭背景偏好。設定入口沿用現有表格工具列；沒有新增重複的頁面設定。
2. 明確使用自然高度與自然空資料高度，不採全頁剩餘高度計算；不綁定其他表格的工具列高度。
3. 保留現有資料來源、欄位插槽、條件欄位、操作、匯率行動版卡片及原有外部分頁，不增加第二組分頁。既有對帳差異專用空資料文字保留，新遷移表格一般空資料文字使用繁體中文。
4. 這 10 個檔案中的固定像素圓角改用既有全域圓角變數。摘要卡片沿用儀錶板的衍生圓角公式，內部小區塊沿用 Element Plus 全域基本圓角。
5. 逐檔比對確認業務 script 區塊未變（忽略排版空白）；不改日期、精度、金融公式、角色、資料來源或 API。

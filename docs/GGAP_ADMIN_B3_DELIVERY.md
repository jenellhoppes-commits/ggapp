# B3：深色側欄配色修復與共用表格延續

日期：2026-09-07；本地修改，未部署 GitHub。

## 截圖問題與處理

使用者截圖顯示「淺色頁面＋深色選單」時，側欄未選取文字與圖示接近黑色。原因是 GGAP 分組側欄取用全頁 Element Plus 文字／背景變數，未使用設定中心已選取的選單主題。原先 `.dark` 選取樣式也只跟隨整體深色模式。

- 將設定中心的 `getMenuTheme` 傳給分組側欄，使用共用配色轉換函式，讓文字、圖示、分組標題、子項連線、移入、選取、鍵盤焦點與行動版關閉按鈕跟隨選單主題。
- 深色選單選取狀態沿用現有傳統選單的白字與深灰底，不依賴全頁 `.dark`。
- 修正全域深色選單的無效瀏覽器色值 `rgba(#FFFFFF, 0.7)`，改為合法 CSS 色值。
- 側欄按鈕與項目圓角改為既有全域變數。未修改導覽路由、折疊與群組展開流程。

## 共用表格延續

操作紀錄、維護排程、網路名單 3 個檔案共 5 張表格改接既有 ArtTable，保留原資料、欄位、專用空資料訊息、操作及分頁；不強制覆寫邊框、斑馬紋或尺寸，使用自然高度。

累計本次表格契約檢查涵蓋 13 個檔案、26 張表格宣告，不代表其他總後台頁面已全數遷移。

## 驗證與限制

- 型別檢查通過；ESLint 454 個檔案，0 錯誤、0 警告；11 組靜態／本地模擬檢查通過。最終本地建置通過（46.67 秒），預覽 HTTP 200；差異空白檢查通過（既有 Windows 換行提示保留）。

- 新增側欄配色測試：深色、淺色、設計風格與深色全頁配色輸入；響應式切換、文字及圖示的色值接線。深色選單一般／移入／選取文字的指定色值對比測試通過 4.5:1。
- 擴充表格模板編譯及資料來源、欄位、分頁保留檢查。
- 瀏覽器實際渲染、不同版面與鍵盤操作尚待畫面驗收；色值計算及靜態接線檢查不能取代真實瀏覽器驗收。
- 側欄水平／雙列等其他組件並未在此批重新設計；正式權限、財務規則及 B1 尚未開放功能維持待辦。

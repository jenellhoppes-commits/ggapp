# B5：實際瀏覽器驗收與行動版修復

日期：2026-09-07。環境：本地 3017 預覽、獨立 Chrome 無頭視窗、演示管理員；桌面 1440×1000、行動版 390×844。沒有使用或修改使用者個人瀏覽器分頁、設定或正式資料，沒有部署 GitHub。

## 驗收結果

這次使用內建 Playwright 與獨立 Chrome 成功完成真實瀏覽器操作，取代先前「只有靜態測試」的限制，但僅限以下頁面與情境。

| 情境 | 結果 |
| --- | --- |
| 演示登入 | 透過登入頁拖動本地演示滑塊並登入成功 |
| 淺色頁面＋深色側欄 | 實際文字色 rgb(186,187,189)、背景 rgb(25,26,35)，截圖確認可讀 |
| 整體深色主題、切回淺色、側欄收合 | 操作成功；有實際深色頁面截圖 |
| 供應商對帳表格偏好 | 勾選邊框、斑馬紋、表頭背景並切換緊湊尺寸；狀態與表格呈現確認 |
| 分頁 | 維持單一分頁器；下一頁資料改變，回上一頁恢復 |
| CSV | 觸發真實瀏覽器下載並存下供應商對帳 CSV；確認欄位與首筆資料，16 筆篩選結果 |
| 空資料 | 輸入不存在關鍵字後出現空狀態；重置恢復資料 |
| 390px 對帳清單 | 修復後沒有固定欄遮擋，橫向捲動可到達右側操作欄；整頁寬度沒有溢出 |
| 行動版側欄 | Tab／Shift+Tab 首尾循環通過；Escape 關閉後焦點回到側欄開關 |
| 390px 儀錶板 | 頁面沒有水平溢出；查詢／重置間距實際為 8px |
| 跨頁偏好 | 進入後台帳號頁後，緊湊、邊框與斑馬紋保持 |
| 執行錯誤 | 本輪沒有未捕捉的 pageerror；不等同所有外部網路請求皆成功 |

## 發現並修復

1. 窄螢幕對帳表格的左右固定欄占用大部分寬度，使中間欄位難以閱讀。三類對帳共用清單改為寬度小於 768px 不固定兩側欄位，桌面保留固定欄。實際操作驗收供應商對帳；其他兩個模式共用程式，但未逐模式重新操作。
2. 儀錶板行動版查詢／重置並排時沒有間距。新增 8px 欄距，實際 CSS 與截圖確認。

# B6：篩選排版與日期快捷選項

日期：2026-09-07。本地修改，未提交、推送或部署。

## 修改範圍

- 儀錶板、報表查詢、匯率、對帳、帳號及語言設定篩選表單採用共用 AppFilterForm。
- 代理、商戶、注單與交易流水沿用 ArtSearchBar，與 AppFilterForm 共用 100px 標籤寬度、640px 行動版切換基準。桌面標籤置左、手機改為上下排列，保留個別欄位明確覆寫能力。
- 儀錶板移除篩選區多餘的操作標題、必填星號；進階欄位移回表單內，保留驗證與查詢行為。
- 查詢／重置順序與按鈕間距統一；修正設定工作區網格最小寬度，避免語言頁撑寬手機畫面。編輯彈窗不在此次篩選遷移範圍。
- 儀錶板與報表查詢日期選擇器左側新增本日、昨日、本週、上週、本月、上月。其他日期欄位未全面遷移。

## 日期規則

- 使用平台預設時區，不使用固定演示日期；每次點擊重新計算，平台時區變更及跨日後不會沿用舊值。
- 週一為每週起點。本週／本月截止今天，上週／上月為完整期間。
- 點選只更新日期草稿，仍需按查詢套用。既有資料範圍與權限驗證不變，快捷選項不會產生演示範圍以外的資料。

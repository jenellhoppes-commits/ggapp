# GGAP 七區塊功能與欄位詳細規格

版本：GGAP-FIELD-SPEC-REVIEW v1.0

日期：2026-09-05

狀態：供使用者確認的完整欄位方案，尚未交安排派工。依使用者架構圖與既有已確認規格整合；新增規則列為本版建議，不以本文件自行批准金流、敏感權限或正式部署。

後續呈現優化及新增利潤需求整理於 [GGAP_UX_FUNCTION_OPTIMIZATION_REVIEW.md](GGAP_UX_FUNCTION_OPTIMIZATION_REVIEW.md)。本文件列的是完整資料欄位，不表示全部都要同時出現在列表；常駐/進階/詳情的安排依優化稿審閱。運營報表新增利潤需求後，收入與全部成本口徑尚待定，不能直接用投注額計算。

## 0. 使用方式與可行範圍

每項功能列出位置、查詢欄位、列表欄位、表單/詳情欄位、資料來源、操作及驗收。葉節點如新增商戶、綁代理、調費率放在物件頁內，不全都開成獨立選單。

三種資料狀態：**沿用**＝已確認業務規則；**建議**＝本版為補齊可執行流程提出；**待定**＝缺業務決策或來源，只可草稿/唯讀/缺項提示，不能顯示為已可正式執行。

本版對疑義採以下最小方案，仍待使用者確認：

| 疑義 | 本版建議 | 明確不包含 |
| --- | --- | --- |
| 圖中兩個代理結算 | 其中一個改為商戶結算，保留供應商/商戶/代理三主體 | 合併三種應結對象 |
| 商戶錢包 | Wallet模式＋幣別線路配置 | 預付商戶資金、信用額度、儲值/提款/人工調額 |
| 補單/重送 | 第一版異常清單、原单查詢、只讀查單；通知重送另行確認 | 重新扣款、重派彩或人工補帳 |
| 白名單/黑名單 | 先限商戶API來源IP，按商戶/環境分開 | 玩家風控、會員黑名單、供應商回呼與後台登入共用政策 |
| 維護設定 | 平台按環境的維護狀態/提示，限制新啟動 | 排程引擎、直接終止全部session、停止合法既有派彩/退款 |

商戶/代理入口仍屬後續細規；本版是平台管理者操作欄位。四報表金額與去重口徑沿用 [正式報表規格](GGAP_REPORTS_FOUR_TABS_DEV_SPEC.md)，本版僅提議移至報表中心及按圖片排列。

## 2. 全站共用欄位與操作

### 2.1 欄位標示

「必填」對新增/編輯表示必須提供，對唯讀欄位表示必須有資料来源或明確缺值狀態；不能要求人員手填交易原值。「條件必填」在相應模式/啟用/正式確認前才驗證。來源缺失保留草稿並提示，不偽造值。

| 共用欄位 | 類型 | 來源/規則 |
| --- | --- | --- |
| 系統識別 | 系統字串、唯讀 | 系統建立，不用名稱當唯一鍵 |
| 商務代碼 | 文字 | 按商戶/代理/供應商類型唯一，建立後不任意改作別的對象 |
| 名稱 | 文字 | 去除首尾空白，不可全空白，保留完整名稱提示 |
| 幣別 | 單選字典 | 平台已設定且對目前對象可用；不硬編全部幣別 |
| 環境 | 單選 | 測試/正式明確區分，資料與憑證隔離 |
| 金額 | 精確十進位 | 同時顯示幣別，依來源精度，不用浮點或10K文字計算 |
| 比例/費率 | 十進位＋單位 | 範圍依核准合約，不能一律假設0–100或允許任意值 |
| 日期時間 | 帶時區時間 | 顯示平台/合約時區，來源可存UTC；不偷偷按瀏覽器時區換日 |
| 生效/失效時間 | 起訖时间 | 起點包含終點不含，結束晚於開始；同範圍版本不無規則重疊 |
| 狀態 | 中文文字＋色彩 | 值依資料來源，成功/失敗/待確認不能混用 |
| 建立/更新者與時間 | 系統唯讀 | 由成功操作產生 |
| 版本 | 系統唯讀 | 編輯需比對，衝突保留输入，不覆蓋他人更新 |
| 異動原因 | 多行文字 | 費率/代理關係/啟停/敏感設定等重要異動條件必填 |
| 備註 | 多行文字、選填 | 不存密碼、憑證或完整敏感資料 |
| 無資料值 | 顯示狀態 | 未知用—/待確認，真實0才顯示0 |

### 2.2 共同行為

- 查詢有查詢/重置，Enter可提交；未套用條件不改列表。查詢/每頁筆數變更回第1頁。
- 所有大量列表及詳情內明細10/20/50分頁，按原值穩定排序；報表預設20筆，其他頁沿既有合理預設。
- 清單與詳情相同主鍵/來源；編輯成功才回寫，失敗保留輸入。未存關閉/離頁提醒。
- 所有敏感動作須明確權限、條件及結果；無來源或無能力不提供假成功。
- 匯出完整已套用查詢範圍，不只目前頁，與列表相同授權/遮罩。
- 本版任何百分比、單位、狀態及欄位英文名稱都不表示正式商務公式已核准；工程可以沿用等義現有欄位，不需為改名重建資料。

## 5. BS-02 代理佣金條件

- 放在代理詳情分頁，不另建第二套代理資料。
- 查詢：適用商戶、條件狀態、生效期間。
- 列表：條件版本、適用範圍、基礎、費率/規則摘要、帳期、幣別、生效期間、狀態。

| 欄位 | 必填時機 | 類型 | 來源/驗證 |
| --- | --- | --- | --- |
| 代理 | 固定 | 唯讀 | 目前代理 |
| 條件識別/版本 | 系統 | 唯讀 | 系統建立新版本 |
| 適用商戶/範圍 | 啟用前 | 選擇 | 明確授權與合約範圍，不把可查看商戶等同收佣範圍 |
| 佣金計算基礎 | 啟用前 | 核准規則選擇 | 缺D02則待設定，不新增任意公式輸入 |
| 費率/規則參數、單位 | 規則要求時 | 十進位/依規則 | 參數與已核准基礎相符 |
| 帳期、時區、結算幣別 | 正式計算前 | 條件引用/字典 | 合約來源，非報表日期預設 |
| 生效、失效時間 | 啟用前/選填 | 日期時間 | 同適用範圍不重疊 |
| 異動原因 | 修改生效條件時 | 多行 | 保存原因 |

允許存草稿、查看歷史、建立新版本。原生效版本不覆寫；算佣金在FN-03。是否有負值/追回/多層分配仍依D02，不以商戶費率減成本自行推算。

## 9. BS-06 商戶錢包與幣別新增

商戶錢包在本版提議為配置功能，並非商戶資金帳戶。

- 查詢：幣別、環境、線路狀態。
- 列表：商戶線路ID、幣別、環境、繼承Wallet、狀態、相容/授權供應商數、更新時間。

| 欄位 | 必填 | 類型 | 來源/驗證 |
| --- | --- | --- | --- |
| 商戶 | 固定 | 唯讀 | 目前商戶 |
| Wallet模式 | 固定 | 唯讀 | BS-03繼承，不每幣各改 |
| 幣別 | 是 | 單選 | 平台已接通幣別 |
| 環境 | 是 | 單選 | 同商戶/同幣/同環境唯一 |
| 商戶線路ID | 系統 | 唯讀 | 系統建立 |
| Callback/串接設定引用 | 依Wallet/協定 | 引用/受控編輯 | 使用SY-01同一來源，不能兩處不同值 |
| 線路狀態、開通缺項 | 系統/動作 | 唯讀/啟停 | 同幣授權/能力與必要串接完成後啟用 |
| 授權供應商/遊戲 | 授權時 | 關聯清單 | 由BS-07維護 |

新增幣別建立線路草稿，不儲值、不給額度。有交易的線只能停用，不改識別或刪歷史。第一版不放商戶資金餘額、存款、信用額度、提款欄；若要預付/授信需另規劃帳本。

## 10. BS-07 商戶遊戲授權與啟用檢核

- 查詢：商戶幣別線、供應商、遊戲、授權狀態。
- 列表：商戶線、供應商線、遊戲、幣別、環境、Wallet相容、授權狀態、不可用原因。

| 欄位 | 必填 | 類型 | 來源/限制 |
| --- | --- | --- | --- |
| 商戶幣別線 | 是 | 單選 | BS-06 |
| 供應商線 | 是 | 單選 | VD-02，同環境/同幣/相容 |
| 遊戲範圍 | 是 | 明確遊戲集合 | VD-03具真實線路關聯的遊戲；既有全遊戲授權如保留需明示語意 |
| 授權狀態 | 是 | 動作/選擇 | 由權限與前置檢核控制 |
| 原因、操作者、時間 | 原因條件必填/系統 | 文字/唯讀 | 授權/撤銷留紀錄 |

IP判定依可信連線/代理設定，不信任任意客戶端標頭；不取代簽章。原交易後續處理需按實際入口來源策略確認，不讓未定名單誤擋供應商回呼。玩家黑名單另屬未規劃範圍。

## 30. 可行性、決策與驗收

### 30.1 在本版結構確認後可直接沿用的範圍

基本商戶/代理資料、條件草稿及歷史、Wallet/幣別配置、遊戲授權、會員唯讀、供應商/遊戲/試玩、注單/流水、四報表及既有權限/紀錄，可依既有來源與已確認規則逐項實作。來源缺口要明示；不等於正式後端已可營運。

### 30.2 必須確認才能正式啟用

- 圖中重複代理結算補正商戶結算。
- 商戶錢包接受只做配置，或另有預付/信用資金需求。
- 補單/重送接受第一版只讀追查；如要通知或資金重送另明確授權。
- 維護的環境與新啟動範圍；白/黑名單接受API來源IP及預設政策。

### 30.3 功能完成條件

每個功能ID均應有：對應入口、查詢/列表/表單或唯讀詳情、資料來源、合法操作、錯誤/空值、角色範圍及可重跑證據。

# GGAP 本地原型至最新規格修改清單

版本：GGAP-CHANGE-4STAGE v1.0｜2026-09-05

2026-09-05 覆蓋決議：財務導航、匯率、維護、網路名單、開發者中心及共用 UI／UX 要求已由使用者確認，依 [GGAP_APPROVED_MVP_DECISIONS_20260905.md](GGAP_APPROVED_MVP_DECISIONS_20260905.md) 執行。與該文件衝突的待確認或較寬功能範圍停止沿用。

第一階段追加 CH-06：側欄改為分區文字標題＋平列圖示功能，不採父層展開箭頭。依 [側欄呈現補充](GGAP_SIDEBAR_PRESENTATION_ADDENDUM.md)；僅參考使用者附圖呈現方式，不恢復圖中的獎池等舊功能。

依據：使用者已確認提交最後的完整規格與修改清單，並依四階段逐次確認執行。最高優先序與階段門檻見 [四階段執行基準](GGAP_FOUR_STAGE_EXECUTION_SPEC.md)。本清單核對現有來源及暫停前驗收紀錄，不宣稱本次已重新畫面驗收。

## 3. 已知缺失與驗收債務

- 第1階段修復 GGAP-R4T-001：查詢外商戶的資料缺口不能污染本範圍完整結果。
- 第1階段修復 GGAP-R4T-002：排序控制可聚焦、可鍵盤操作及辨識狀態。
- 四報表已有獨立56領域案例55過1失敗及實際CSV下載；重用有效證據，修改影響處複驗。完整UI／200%等缺口按本階段修改完成核對。
- 第2階段 R02-001 精確遊戲線路来源缺口保留清楚狀態並完成可落實查詢；不可猜配。R02-002/003已有邏輯修復，補真實抽屜分頁／未存提醒／窄畫面與鍵盤，不重寫已正確部分。
- 第3階段回歸四報表精確注單承接、旧路由及範圍隔離，不能因一般交易整併放寬既有報表查詢。
- 第4階段逐項核對31功能，全部適用成本是否可追溯與未齊提示，資料／權限／歷史／匯出一致；正式未接事項單獨列示。

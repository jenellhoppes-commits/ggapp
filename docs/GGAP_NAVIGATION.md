# GGAP 導覽現況與範圍調整

本文件記錄導覽現況，不把占位入口視為已確認需求。最新範圍以 [第 1、2 階段重新對齊清單](./GGAP_REALIGNMENT_PHASE1.md) 為準。只修改獨立 game-admin 專案，不改動其他本地專案，也不提交或推送遠端倉庫。

## 管理者選單

側邊選單保留「首頁」「營運管理」「財務管理」「平台管理」分區小標題；同一分區只顯示一次，子選單不重複顯示。

1. 儀錶板
2. 商務管理：代理、商戶，以及隱藏的建立／詳情／商戶幣別線頁
3. 供應商管理：供應商列表、遊戲列表、試玩連結三頁籤；供應商詳情與遊戲編輯採抽屜，顯示標籤移入遊戲編輯
4. 交易中心：會員與錢包、注單、交易流水、遊戲局號、轉點、補單
5. 財務管理：總覽、商戶應收、供應商應付、代理佣金、調帳、匯率
6. 報表中心：營運、遊戲、商戶、代理、會員、交易、結算、供應商
7. 系統管理：帳號與權限、幣別、語系、通知、參數、稽核、審核、開發者中心

供應商模組的新路由、演示能力與正式後端接入限制，詳見 [供應商演示說明](./GGAP_PROVIDER_DEMO.md)。

只有一個可見子頁的選單直接連至該頁，不顯示多餘的父子層；隱藏詳情頁不計入子頁數。此規則套用側邊、雙列與水平選單，保留原有網址、權限、分區標題與詳情選取狀態。

## 其他角色

- 代理：總覽、推廣商戶、串接進度、營運摘要、我的佣金、佣金付款紀錄。
- 商戶：總覽、幣別線、API 串接、可用遊戲、試玩連結、會員與錢包、注單、交易流水、結算明細、帳單與付款。
- 首頁由角色過濾後的選單決定；不得統一導向管理者儀表板。
- 正式資料權限需由後端權杖驗證。前端選單隔離僅是開發演示，不構成正式安全邊界。

## 功能狀態

沿用既有示範實作：供應商、商務、遊戲清單、會員、注單、交易流水、匯率及系統作業。

明確標示「待開發」：遊戲局號、轉點、補單、先前財務占位頁（待核對原流程）、正式結算報表、供應商報表、開發者中心，以及代理／商戶其餘規劃頁。商戶試玩連結已實作為授權隔離的前端演示，不執行資金操作。

舊版財務頁保留原始檔案，目前未註冊為可操作入口；舊代理對帳／代理結算轉至佣金占位頁，不移轉任何舊金額。這是先前整理的現況，不代表刪除原流程已獲確認；後續須核對原遊戲商流程，再決定恢復或調整，不能直接套用另建的佣金模型。舊獎池管理轉至交易流水，只保留查詢事件的語意。

## 網址相容

- `/members/management/:id` → `/transactions/members/:id`
- `/risk/...`、`/platform/risk/...`、`/quality/...` → `/dashboard`；品質／風控本期不開放
- `/approvals/...` → `/platform/approvals/...`
- `/finance-settings/currencies/...` → `/platform/currencies/...`
- `/finance-settings/exchange-rates/...` → `/finance/exchange-rates/...`
- 舊商戶結算／帳單 → 新商戶應收規劃頁
- 舊代理對帳／結算 → 新代理佣金規劃頁
- 舊書籤有合理對應頁時保留參數、查詢與頁內定位；詳情的選單高亮回到新的列表位置。

## 本地驗證

`pnpm dev` 固定使用 `http://127.0.0.1:3016`，若埠已占用就報錯，不自動換埠。原專案的 3006 不受影響。

`pnpm test:navigation` 檢查路由唯一性、元件存在、主選單、所有頁面與舊轉址落點、詳情高亮、角色首頁與跨入口隔離。

`pnpm lint` 與 `pnpm build` 分別進行程式品質、型別與正式打包驗證。

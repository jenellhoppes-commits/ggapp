# 供應商整合與試玩第一版

## 已實作的前端演示

- 側邊只保留「供應商管理」。頁內切換 `/admin/providers`、`/admin/providers/games`、`/admin/providers/demo-links`。
- 供應商詳情採六頁籤抽屜：基本資料與狀態、幣別線與串接設定、遊戲、成本與結算設定、供應商對帳、操作紀錄。
- 遊戲編輯抽屜可編輯顯示名稱、顯示標籤與上架狀態；RTP 與支援語系唯讀。無獨立標籤頁。
- 舊供應商、遊戲、標籤與詳情網址轉址至整合頁；詳情仍可直接開啟抽屜。
- 試玩連結支援建立、查看、開啟模擬流程、複製、停用、重新產生。一次只綁定一供應商、一遊戲、一幣別線、一試玩方式。
- 原生試玩優先，核准測試帳號為次選。無支援或未確認供應商免計費時禁止建立；不以正式帳號代替。
- 商戶入口 `/merchant/demo-links` 使用相同元件；示範帳號 merchant 固定對應 M00001。只能查看、建立、操作自身商戶連結。
- 商戶幣別線「串接測試」固定使用該線測試憑證識別碼，提供啟動、餘額、下注、派彩、退款、回滾；轉點模式再提供轉入、轉出。顯示回呼、錯誤碼、時間、耗時與追蹤識別碼。
- 正常與回呼逾時情境可切換；結果標示模擬，不再將按鈕點擊視為真正串接成功。前端模擬不開放正式環境申請。

## 演示邊界

本版沒有新增後端、供應商 API 或真實可玩的遊戲。`/play/:token` 為模擬啟動頁，建立不同連線識別碼並累計模擬成功次數，不產生或儲存供應商啟動網址。沿用模板雜湊路由，實際網址為 `http://127.0.0.1:3016/#/play/:token`。

所有供應商能力、遊戲歸屬、商戶授權及供應商計費排除都是固定示範設定，並非實際供應商合約事實。初始額度僅在示範供應商支援時顯示。

資料只儲存在目前瀏覽器的 `ggap-provider-demo-v1` 與 `ggap-integration-demo-v1`，不能跨裝置分享，不是安全邊界，也不保證跨分頁併發的原子次數限制。停用只阻止新的模擬啟動；舊連線紀錄仍保留。重新產生使舊 token 失效、歸零新連結計數，保留歷史連線紀錄。

試玩與串接測試使用獨立資料集合，不寫入正式會員、錢包、注單或財務 store；不呼叫任何正式資金端點。網址參數不能切換其帳務身分。測試每次建立新的測試會員與隔離錢包，初始 1000 單位僅為測試資料，與供應商可調額度無關。

成本合約與對帳抽屜只呈現整合入口及待接入狀態，不偽造正式費率或對帳結果。此版不做帳號池、SEO 嵌入、輪替租借、租期回收或獨立試玩大廳。

## 正式後端接入前必做

1. 從登入身分、商戶／幣別線授權與供應商能力建立權限；不相信前端角色、用途或環境參數。
2. 原子檢查連結到期、撤銷、成功啟動上限、遊戲及供應商狀態、商戶授權；處理併發預留與失敗回補。
3. 每次取得獨立 Session 與短效 Launch URL；僅後端持有憑證，分享連結不得包含密鑰或真實會員資料。
4. 明確確認供應商核准的測試帳號、免計費與終止連線能力；沒有核准便禁止啟用。
5. 真正隔離測試錢包、會員、事件與正式資金流程；由後端設定試玩／測試身分，報表與各條結算線排除非正式事件。
6. 真正執行商戶測試回呼與冪等／錯誤案例，留存 Trace；驗收通過後才能申請正式環境。

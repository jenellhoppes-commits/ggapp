## 2. 呈現規格

- 左側沿用深色底與現有品牌區；分區標題以較小、低強調但可讀的灰色文字呈現。
- 分區標題是純標題，不是可點擊父選單；不加展開箭頭、不需要先點分類才能看到功能。
- 展開寬度下，各分區功能直接顯示，層級一致，不在每一區額外增加第二層縮排。
- 功能列為圖示＋文字，整列可點；選取頁以圓角深色背景、藍色圖示／文字突出，滑過及鍵盤焦點可辨識。
- 分區之間用留白區隔，不加紅框、粗分隔線或卡片外框；避免過多粗體與狀態標籤。
- 側欄過長時可垂直捲動，當前頁保持可到達且可辨識，不為塞進單一螢幕而縮小到難讀。配色沿用現有主題，圖示沿用現有圖示系統。
- 可保留整個側欄收合為圖示的控制，與分區手風琴不同；圖示模式提供功能名稱提示、鍵盤可達與作用中狀態。窄畫面用可關閉的覆蓋導航，打開後仍按分區列功能。
- 只顯示有查看權限的功能；沒有任何可見功能的分區不顯示空標題。分區標題採語意分組，不作可操作按鈕。
- 詳情頁／編輯頁沿用其所屬功能的選取狀態；舊網址導向後也要選中正確項目。

## 3. 最終導航內容

| 分區標題 | 直接列出的功能 |
| --- | --- |
| 總覽 | 儀錶板 |
| 商務管理 | 代理管理、商戶管理、會員與錢包 |
| 廠商管理 | 供應商管理、遊戲管理、試玩管理 |
| 交易中心 | 注單管理、交易流水 |
| 財務中心 | 供應商結算、商戶結算、代理結算 |
| 報表中心 | 報表查詢 |
| 系統管理 | 開發者中心、維護設定、白名單／黑名單、人員與權限 |

報表查詢頁內維持運營／代理／商戶／遊戲四分頁，不在側欄再列四份報表。人員／角色仍頁內兩分頁。新增、費率、授權、同步及操作紀錄按原規格在相關頁內，不新增側欄項。

## 4. 第一階段交付與驗收

第一階段包含此呈現調整，不等後續階段。使用者確認前需提供本地可開連結與側欄截圖，核對七分區順序、直接可見功能、選中／滑過／焦點、捲動、收合與窄画面行為。所列後續階段頁面的完成程度仍按四階段清單說明，不以入口出現宣稱功能完成。現有合法角色權限與路由不放寬；已退役功能不恢復。

每階段仍必須完成後回傳本地連結、等待使用者明確確認後才能開始下一階段。

# GGAP v2.2 補充：試玩管理獨立頁面

日期：2026-09-04

依使用者最新決議，管理者側欄新增獨立「試玩管理」，網址為 `/trials/links`。供應商管理只保留供應商列表與遊戲列表，不再包含試玩連結頁籤或試玩統計。

- 沿用既有 DemoLinks、Store 與演示權限，不複製另一套試玩資料。
- 新頁保留建立、查看、複製、啟動、停用與重新產生連結等既有操作。
- 遊戲列表「建立試玩連結」跳至獨立頁，帶入遊戲識別。
- `/admin/providers/demo-links` 舊網址導向新頁，保留查詢參數與 hash。
- 已建立連結與公開 `/play/:token`、Session 及資料識別不變。
- 商戶自身試玩頁保留既有範圍；代理不新增試玩權限。
- 本次不修改正式串接、佣金、財務公式，也不宣告完整 v2.2 已完成。

v2.2 PRD 中「試玩與供應商／遊戲同一頁籤」改以本補充為準；試玩仍引用供應商線路與遊戲能力，而不是與供應商資料脫離。

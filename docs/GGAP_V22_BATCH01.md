## 本批交付

1. 供應商列表：明確查詢／重置、名稱／代碼／狀態／幣別／環境／錢包條件、原值排序、10／20／50 分頁，非敏感條件與詳情保存網址。跨線條件須由同一條線符合。
2. 新增／編輯基本資料：唯一代碼、必填、長度檢查、建成後代碼唯讀、版本衝突；沿用同一詳情抽屜，不疊第二層。
3. 線路：環境、帳號與幣別識別、HTTPS API URL、平台 Callback 示意、Wallet、精度、最小單位。重複供應商／幣別／環境先阻擋，D08 後再處理多帳號政策。
4. 憑證：只產生 DEMO-CRED 識別、非密鑰遮罩說明與更新時間；專用確認操作，需要原因。沒有輸入／保存真實密鑰的欄位，也不發出網路請求。
5. 模擬設定測試與逾時：保存時間、追蹤識別、結果；改設定或重設憑證清除舊結果，停止新啟動。測試成功不等於啟用。
6. 啟用檢核：列出設定、測試、種子精度／Wallet 能力、遊戲來源與試玩核准缺項。只允許已有示範能力的 Sandbox 線人工啟用；新增 Provider 預設沒有能力，正式設定不能啟用。
7. 供應商／線路維護與停用：確認原因、影響摘要、操作紀錄；不刪 Session、不重算金額、不執行既有交易金流。影響商戶數取自試玩授權種子，非正式所有商戶總數。
8. 取消編輯提醒、表單驗證、版本衝突保留輸入、窄螢幕單欄；列表與線路、遊戲、操作紀錄明細分頁。
9. 共用 listPage 純函式供後續模組沿用；既有標籤只作輕量屬性，不新增標籤管理或分組模組。

## 資料相容與限制

- 使用原供應商本地資料集合（實際鍵名為 `ggap-provider-demo-v1`）。保留原 Provider／線路／遊戲／連結識別與 Session。
- 舊線路補齊「測試種子」設定與 FIXTURE 測試來源；不是自動驗證正式環境。新線路從待設定開始。
- 本期精度表單範圍 0–8 是演示限制，不代表所有供應商與幣別的正式規格。既有 TWD／USD、Seamless 能力為固定測試情境；其他組合不自動認證。
- 供應商列表更新時間目前表示基本資料版本時間；線路另有自身版本與更新時間。
- 共用語系、全站導航、遊戲主列表查詢分頁、三入口 DTO／細粒度權限、API 匯出、真正遊戲同步、成本條件版本及對帳工作頁仍待後續批次。
- 瀏覽器 localStorage 不提供服務端權限、跨裝置分享、併發原子性或秘密儲存；讀取本地資料不代表正式授權。
- 未決財務條件只阻擋正式計費／佣金／確認，不阻擋一般查詢。已確認結果不能直接作廢；來源須按財務類型及對象防重，後續模型不可採全域已結算旗標。
- 歷史權限與歸屬生效規則尚待 D06／D08；未引入依目前代理歸屬回填歷史的邏輯。
